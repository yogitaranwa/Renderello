# Anonymized review packs for human raters

Optional local Python interface, not a default route. `renderello.blind_review.build_pack` (the module keeps its original name) prepares a review pack so a human rater can score candidates without seeing which method made each image. It accepts one source, two to twelve candidates, a new output path, an explicit random seed, and optional named native-coordinate crops. A candidate has a method identity held in a private key, either an output path or an explicit failure. Duplicate output content and duplicate method labels are rejected; failed generations stay in the denominator rather than disappearing from review.

The REVIEW folder contains anonymous candidate IDs, normalized full-resolution images, source and candidate crop pairs, a checkerboard overview, and an entirely blank seven-dimension rating CSV. PRIVATE contains the source paths, method mappings and hashes. Only REVIEW is for raters. Random order is reproducible, not cryptographic secrecy or authenticated independent evaluation. Familiar outputs may reveal their methods. Source/candidate dimensions must agree; different layouts need an explicit registration path rather than silent stretching.

`verify_pack` checks completed initial pack contents against recorded hashes, rejects path escapes/symlinks and unlisted review files. It verifies construction integrity, not rater identity or acceptance. Editing the rating sheet intentionally changes its construction hash; preserve the original pack and collect scored sheets separately. No automatic scores, winning methods, inferred humans or acceptance claims are generated.

Full-resolution crops make small print and edges inspectable, but only a person can determine semantic label correctness, shadow plausibility or glass optics here. Colour-managed intake can change decoded RGB when an ICC profile is present, and derivative PNGs are not original encoded bytes. Source files are read only. An incomplete write has no COMPLETE.json and must not be consumed. Existing destinations are never replaced.
